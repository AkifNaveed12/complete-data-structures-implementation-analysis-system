# CDSIAS — Comprehensive Data Structure Implementation & Analysis System

A professional desktop-based Data Structure Laboratory System built using **C++**, **Qt 6**, and **CMake**, focused on the manual implementation, visualization, and performance analysis of core data structures and algorithms without relying on STL containers.

---

# Overview

CDSIAS bridges the gap between theoretical learning and practical understanding of data structures by providing an interactive environment where users can:

- Visualize operations step-by-step
- Analyze algorithm performance
- Explore internal working mechanisms
- Compare implementations and complexities
- Learn data structures interactively

The project follows a modular software engineering architecture and was developed as a semester project for Data Structures & Algorithms.

# How To Run

## Windows Users

1. Extract the ZIP file
2. Open the extracted folder
3. Run:

```text
cdsias_gui.exe
```

No additional installations are required.
